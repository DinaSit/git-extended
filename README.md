# git-extended

Тестовый репозиторий для изучения GitFlow, Conventional Commits и семантичесого версионирования.

## Gitflow

В репозитории используется модель ветвления Gitflow. Основная разработка
выполняется в ветке `develop`, новые изменения — в ветках `feature/*`,
а подготовка версий — в ветках `release/*`. Ветка `master` содержит
стабильные выпуски проекта.
